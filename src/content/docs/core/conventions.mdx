`UBot Conventions Library` 为蓝图提供位置、旋转、角速度和刚体变换的双向转换，支持 UE（左手坐标系，长度单位为厘米）与 FLU（前、左、上，采用国际单位制的右手坐标系）之间的数据交换。

该右手坐标系符合 ROS 的 REP-103 坐标约定，也适用于模型 X 轴朝前、Z 轴朝上的 MuJoCo 等右手坐标系引擎，因此节点采用与协议无关的名称：`UE To Right-Handed …` 和 `Right-Handed To UE …`。转换时需要处理 Y 轴方向差异；位置和变换的平移分量还需要在厘米与米之间换算。

## 快速用法

以下示例将 Actor 的 UE 位置（厘米）转换为右手坐标系位置（米），并显示在屏幕上：

```blueprint
caption: 每帧显示 Actor 在右手坐标系中的位置
nodes:
  A: AActor.ReceiveTick
  G: AActor.K2_GetActorLocation
  C: UUBotConventionsLibrary.PositionUEToROS
  V: UKismetStringLibrary.Conv_VectorToString
  P: { ref: UKismetSystemLibrary.PrintString, set: { Key: right_handed_position } }
wires:
  - A.then -> P.execute
  - G.ReturnValue -> C.UECentimeters
  - C.ReturnValue -> V.InVec
  - V.ReturnValue -> P.InString
notes:
  C: 图中使用旧名称 `UE To ROS Position`，0.1.3 起请用 `UE To Right-Handed Position`，结果相同。
```

反向转换使用 `Right-Handed To UE Position`。

## 步骤

<Steps>

1. **找到数据对应的节点**

   在节点菜单中搜索 `Right-Handed`，根据数据类型选择对应节点，具体对应关系见“关键属性”。搜索关键词 `ROS` 也可以找到这些节点。

2. **选对方向**

   向采用右手坐标系的系统发送 UE 数据时，使用 `UE To Right-Handed …`；将右手坐标系数据引入 UE 时，使用 `Right-Handed To UE …`。

3. **检查输入的单位**

   位置和变换节点会换算长度单位。向量、角速度和航向角节点只转换坐标方向，不转换单位，因此输入应已使用对应的国际单位制单位，例如 m/s、rad/s 或 rad。

</Steps>

### ROS 专属的节点

相机光学坐标系、ROS 时间和 ROS 名称属于 ROS 专用约定。从 uBotCore 0.1.3 起，对应节点由 uBotROS 的 `UUBotROSConventionsLibrary` 提供，位于类别 `uBot|ROS|Conventions` 下，节点名称和显示名称保持不变：

| 节点 | 作用 |
| --- | --- |
| `Camera Link To Optical Rotation` | 返回相机光学坐标系（z 向前、x 向右、y 向下）相对相机本体坐标系（camera link frame）的旋转，遵循 ROS 约定 |
| `Get Optical Frame Suffix` | 返回光学坐标系标识（frame id）的后缀 `_optical` |
| `Seconds To ROS Time` | 将以秒表示的时间转换为 `builtin_interfaces/Time` 的 `Sec` 和 `Nanosec` |
| `ROS Time To Seconds` | 将 `Sec` 和 `Nanosec` 合成为以秒表示的时间 |
| `Sanitize ROS Name` | 将任意文本转换为合法的 ROS 名称片段 |

uBotCore 中的同名节点已弃用，但行为保持不变，现有蓝图仍可运行。使用迁移后的节点需要在项目中启用 uBotROS。

### 时间转换

ROS 的时间戳（`builtin_interfaces/Time`）由整数秒 `Sec` 和纳秒 `Nanosec` 两部分组成。`Seconds To ROS Time` 将以秒表示的时间拆分到这两个字段，`ROS Time To Seconds` 执行反向转换。

```blueprint
caption: 每帧将仿真时间转换为 ROS 时间戳，并显示 Sec 字段
nodes:
  A: AActor.ReceiveTick
  S: { inline: { title: UBot Clock Subsystem, kind: pure, outputs: [{ name: Return Value, type: "object:UUBotClockSubsystem" }] } }
  T: UUBotClockSubsystem.GetSimTimeSeconds
  R: UUBotConventionsLibrary.SecondsToRosTime
  C: UKismetStringLibrary.Conv_IntToString
  P: { ref: UKismetSystemLibrary.PrintString, set: { Key: ros_sec } }
wires:
  - A.then -> P.execute
  - S.ReturnValue -> T.Target
  - T.ReturnValue -> R.Seconds
  - R.Sec -> C.InInt
  - C.ReturnValue -> P.InString
notes:
  S: 搜索 `Get UBotClockSubsystem` 获取时钟子系统引用，具体用法见“仿真时钟”。
  R: "图中使用 uBotCore 中已弃用的节点，uBotROS 中的同名节点用法相同；`Nanosec` 未连接。"
```

例如，12.5 s 转换后， `Sec` 为 12、`Nanosec` 为 500000000。

### 名称净化

`Sanitize ROS Name` 的规则与 uBotCore 的 `UBot::Identity::SanitizeNameToken` 相同，输入输出示例见[标识与命名](/concepts/identity/)。

## 关键属性

该函数库没有可配置属性，下表列出节点及其转换规则。反向转换采用相同的坐标分量映射；位置和变换的平移分量则从米转换为厘米，即乘以 100。

| 数据 | 节点 | UE 转右手系 |
| --- | --- | --- |
| 位置（cm 到 m） | `UE To Right-Handed Position`、`Right-Handed To UE Position` | `(x, -y, z) / 100` |
| 线性量（线速度、加速度、已采用米的点坐标） | `UE To Right-Handed Vector`、`Right-Handed To UE Vector` | `(x, -y, z)` |
| 角速度（rad/s）、力矩等轴向量 | `UE To Right-Handed Angular Velocity`、`Right-Handed To UE Angular Velocity` | `(-x, y, -z)` |
| 旋转四元数 | `UE To Right-Handed Rotation`、`Right-Handed To UE Rotation` | `(x, y, z, w)` 变为归一化的 `(-x, y, -z, w)` |
| 刚体变换 | `UE To Right-Handed Transform`、`Right-Handed To UE Transform` | 旋转按上述四元数规则转换，平移从 cm 转换为 m，丢弃缩放 |
| 航向角、扫描角、偏航角速度（rad、rad/s） | `UE To Right-Handed Yaw`、`Right-Handed To UE Yaw` | `右手系 = -UE` |

### 已弃用的旧节点

在 uBotCore 0.1.2 及更早版本中，这 12 个节点名为 `UE To ROS …` 和 `ROS To UE …`。0.1.3 起它们已弃用，结果与新节点完全相同，编译时会提示替换为对应的新节点。

新名称将旧名称中的 `ROS` 替换为 `Right-Handed`：`UE To ROS Position` 对应 `UE To Right-Handed Position`，`ROS To UE Yaw` 对应 `Right-Handed To UE Yaw`。

## 输出与事件

所有节点均为纯函数，不提供执行引脚或事件；输出值由输入数据计算得到。位置和变换的平移分量在 UE 转右手坐标系时以米输出，反向转换时以厘米输出。

## 注意事项

- 坐标转换节点仅执行数学换算，不依赖 ROS，也不需要 uBotROS。
- 变换的缩放被丢弃，输出的缩放恒为 1。
- 四元数在转换后会归一化；零长度输入返回单位四元数。
- `Seconds To ROS Time` 遇到负数或非有限值，输出 `(0, 0)`；秒数超出 int32 范围时，`Sec` 取 2147483647，`Nanosec` 取 999999999。
- `ROS Time To Seconds` 将负的 `Nanosec` 按 0 处理。
- `Nanosec` 在蓝图中的类型为 Integer（int32），取值在 0 到 999999999 之间。
