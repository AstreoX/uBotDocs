uBotCore 为各 uBot 插件提供共享契约与基础功能，包括传感器帧头（Frame Header）、仿真时钟（Clock）、Unreal Engine（UE）与右手坐标系之间的坐标转换、机器人标识，以及 Package 查询和编辑器状态面板。

uBotCore 仅依赖 UE 引擎。相机光学坐标系、ROS 时间和 ROS 名称等 ROS 专用转换由 [uBotROS](/ros/) 提供。

## 能做什么

| 功能 | 作用 | 页面 |
| --- | --- | --- |
| 仿真时钟 | 读取仿真时间，设置固定步长，暂停仿真并执行单步 | [仿真时钟](/core/clock/) |
| 坐标约定库 | 在蓝图中转换位置、旋转、角速度和刚体变换，支持 UE 与右手坐标系 FLU（前、左、上，采用国际单位制）之间的双向转换 | [坐标约定库](/core/conventions/) |
| Identity 组件 | 统一配置机器人的 `Robot Id`、`Namespace` 和 `Base Frame Id` | [Identity 组件](/core/identity/) |
| Package 查询与 uBot 面板 | 在编辑器、蓝图和命令行中查看已安装的 uBot Package | [Package 查询与编辑器面板](/core/packages/) |
| 设置项 | 项目设置「uBot Core」和编辑器偏好「uBot」 | [uBotCore 设置项](/core/settings/) |
| 帧头与采样状态 | 所有传感器帧共用的帧头和状态码 | [帧头与采样状态](/concepts/frame-header/) |
| 采样调度 | 传感器按固定频率安排采样时刻，每帧最多采样一次 | [仿真时钟与采样调度](/concepts/clock-and-scheduling/) |
| 传感器、执行器和感知介质接口 | 通过共享接口实现跨插件交互 | [插件之间怎么对接](/concepts/interfaces/) |

## 依赖与安装

<PackageStatus name="UBotCore" />

通过 [uBot Manager](/manager/) 安装依赖 uBotCore 的插件时，Manager 会自动安装所需的 uBotCore；也可以按照[安装说明](/start/install/)手动安装。

## 组件一览

| 组件 | 作用 | 参考 |
| --- | --- | --- |
| `UBot Clock Subsystem` | 仿真时间，固定步长，暂停与单步 | [UBot Clock Subsystem](/reference/ubotcore/uubotclocksubsystem/) |
| `UBot Conventions Library` | UE 与右手系之间的坐标换算节点（`UE To Right-Handed …`） | [UBot Conventions Library](/reference/ubotcore/uubotconventionslibrary/) |
| `uBot Identity` | 配置机器人 Actor 标识的组件 | [uBot Identity](/reference/ubotcore/uubotidentitycomponent/) |
| `UBot Package Library` | 在蓝图中查询已安装的 Package 和扩展点 | [UBot Package Library](/reference/ubotcore/uubotpackagelibrary/) |
| `uBot Core` | 项目设置 | [uBot Core](/reference/ubotcore/uubotcoresettings/) |
| `uBot` | 编辑器偏好 | [uBot](/reference/ubotcore/uuboteditorsettings/) |
| `UBot Frame Header` | 所有传感器帧共用的帧头 | [UBot Frame Header](/reference/ubotcore/structs/fubotframeheader/) |
| `UBot Sensor` | 传感器接口 | [UBot Sensor](/reference/ubotcore/uubotsensor/) |
| `UBot Actuator` | 执行器接口 | [UBot Actuator](/reference/ubotcore/uubotactuator/) |
| `UBot Velocity Commandable` | 能接收速度指令的对象的接口 | [UBot Velocity Commandable](/reference/ubotcore/uubotvelocitycommandable/) |
| `UBot Perception Medium` | 烟、雾等感知介质的接口 | [UBot Perception Medium](/reference/ubotcore/uubotperceptionmedium/) |

完整的类、结构体和枚举列表见 [UBotCore 参考](/reference/ubotcore/)。
