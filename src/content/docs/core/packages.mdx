通过编辑器的 uBot 面板、蓝图和命令行查询已安装的 uBot Package（插件）及其运行状态。

安装、更新、启用和禁用由 [uBot Manager](/manager/) 或下面的命令行完成，uBot 面板和蓝图只负责查看。

## 快速用法

下面在开始运行时检查 uBotSensor 是否已安装且版本满足约束。`Is uBot Package Version Satisfied` 仅检查已安装版本，Package 是否启用不影响结果；`^0.1.0` 表示大于等于 0.1.0 且小于 0.2.0。若还需确认插件已启用，应同时调用 `Is uBot Package Enabled`：

```blueprint
caption: 开始运行时检查 uBotSensor 是否已安装且版本为 0.1.x
nodes:
  A: AActor.ReceiveBeginPlay
  C: { ref: UUBotPackageLibrary.IsUBotPackageVersionSatisfied, set: { Name: UBotSensor, Constraint: "^0.1.0" } }
  B: K2Node_IfThenElse
  T: { ref: UKismetSystemLibrary.PrintString, set: { InString: UBotSensor 0.1.x installed } }
  F: { ref: UKismetSystemLibrary.PrintString, set: { InString: UBotSensor missing or wrong version } }
wires:
  - A.then -> B.execute
  - C.ReturnValue -> B.Condition
  - B.True -> T.execute
  - B.False -> F.execute
```

## 步骤

### 打开 uBot 面板

<Steps>

1. **打开面板**

   点击编辑器菜单「Window > uBot」（窗口 > uBot），或点击状态栏右侧的「uBot: 3 packages · 2 problems」（中文界面是「uBot：3 个 Package · 2 个问题」）。这两个数字是已启用的 uBot Package 数和问题数。

2. **找到面板**

   面板是一个可停靠的标签页，第一次打开时停靠在「Details」面板所在的标签组中。也可以在控制台输入 `uBot.OpenPanel` 打开。

3. **查看状态**

   面板包含下表所列的四个分区。每行前方的圆点表示状态或严重程度：绿色表示正常，灰色表示信息，黄色表示警告，红色表示错误。

   ![uBot 面板：顶部是「Open uBot Manager」按钮，下面是 Loaded Packages、Extension Points、Runtime 和 Problems 四个分区](../../../assets/start/ubot-panel.png)

4. **需要安装或更新时**

   点击面板顶部的「Open uBot Manager」（打开 uBot Manager），启动 Manager 并打开当前项目。旁边的刷新按钮用于重新扫描插件并读取 Package 索引。

</Steps>

| 分区 | 显示内容 |
| --- | --- |
| 「Loaded Packages」（已加载的 Package） | 已启用的 uBot Package 和版本；索引中存在更新版本时显示 `0.1.0 · 0.1.1 available` |
| 「Extension Points」（扩展点） | 已声明的扩展点和各自的实现数量 |
| 「Runtime」（运行时） | 各 Package 发布的运行状态，例如 uBotROS 的「ROS bridge」；「Fixed time step」；PIE 运行期间还显示「Sim time」（每 0.25 s 刷新），没有正在运行的会话时，显示上一次会话的「Last session」 |
| 「Problems」（问题） | 版本不满足、依赖缺失或被禁用、旧插件与 uBot Package 同时启用、运行时问题、Package 索引读取失败 |

### 在蓝图里查询

`Find uBot Package` 按名称查找 Package，不区分大小写。查找成功时，`Return Value` 为 true，`Out Info` 包含该 Package 的信息；使用 Break 节点拆分 `Out Info` 后，可以读取版本号：

```blueprint
caption: 读取 uBotCore 的版本号并打印
nodes:
  A: AActor.ReceiveBeginPlay
  F: { ref: UUBotPackageLibrary.FindUBotPackage, set: { Name: UBotCore } }
  B: K2Node_IfThenElse
  K: { ref: Break:FUBotPackageInfo, hideUnconnected: true }
  P: UKismetSystemLibrary.PrintString
wires:
  - A.then -> B.execute
  - F.ReturnValue -> B.Condition
  - B.True -> P.execute
  - F.OutInfo -> K.UBotPackageInfo
  - K.Version -> P.InString
notes:
  K: "`Version` 位于折叠的高级引脚中，点击节点下方的 ▾ 展开后即可连接该引脚。"
```

### 用命令行查询

`UBotCoreEditor` 提供 `UBotPackage` 命令行工具（commandlet），可在无图形界面环境下执行，适用于持续集成（CI）：

```powershell
$Editor  = '<UE_5.5>\Engine\Binaries\Win64\UnrealEditor-Cmd.exe'
$Project = '<Project>\<Project>.uproject'

& $Editor $Project -run=UBotPackage -List
& $Editor $Project -run=UBotPackage -Validate
```

| 参数 | 作用 |
| --- | --- |
| `-List` | 以表格输出已安装的 Package 及索引中的 Package，包括名称、版本、状态和问题数，并列出每个问题。状态是 `Planned`、`Not installed`、`Enabled`、`Disabled`，启用状态已修改但编辑器尚未重启时是 `Enabled after restart` 或 `Disabled after restart`；表中另有一列供 uBot Manager 分类使用，查询时无需处理 |
| `-Validate` | 校验已安装的 Package；发现任何问题（包括索引错误）时返回失败 |
| `-Install=<Name>[@<Version>]` | 按依赖顺序克隆缺失的必需依赖和该 Package，然后启用它；省略版本时安装最新的可安装版本 |
| `-Update=<Name>` | 在 Package 目录执行 `git pull --ff-only` |
| `-Enable=<Name>`、`-Disable=<Name>` | 启用或禁用；禁用时若仍有已启用的 Package 依赖目标插件，需要添加 `-Force` 同时禁用这些 Package |
| `-Timeout=<Seconds>` | 等待 `-Install` 和 `-Update` 的最长时间，默认 1800 s，0 表示无限等待 |

全部成功时退出码为 0；任一操作失败、`-Validate` 发现问题或参数无效时为 1。`-Install`、`-Enable` 和 `-Disable` 会修改 `.uproject`，需要重启编辑器才能加载新的启用状态。

## 关键属性

`Find uBot Package` 和 `Get Installed uBot Packages` 返回 `UBot Package Info`，常用的字段有：

| 字段 | 含义 |
| --- | --- |
| `Name` | 插件名称，例如 `UBotSensor` |
| `Friendly Name` | 显示名称 |
| `Version` | 语义化版本号，取自描述文件的 `VersionName` |
| `Enabled` | 是否已启用 |
| `State` | `Enabled` 或 `Disabled` |
| `Requires` | 依赖列表：`Name`、版本约束 `Version`、`Optional` |
| `Provides` | 提供的功能标识，例如 `Sensor.IMU` |
| `Problems` | 依赖校验发现的问题，文字描述 |
| `Base Dir` | 插件目录的绝对路径 |

## 输出与事件

### 蓝图节点

以下节点均为 `UBot Package Library` 中的纯函数；该函数库不提供事件：

| 节点 | 输出 |
| --- | --- |
| `Get Installed uBot Packages` | 所有已安装的 uBot Package（不论是否启用），按名称排序 |
| `Find uBot Package` | `Return Value` 表示是否找到，`Out Info` 是 `UBot Package Info` |
| `Is uBot Package Enabled` | 已安装并启用时为 true |
| `Get uBot Package Version` | 已安装的版本号；未安装时返回空字符串 |
| `Is uBot Package Version Satisfied` | 已安装且版本满足约束时为 true；未安装，或版本、约束无法解析时为 false |
| `Get uBot Extension Point Names` | 已声明的扩展点名称，按声明顺序 |
| `Get uBot Extension Names` | 指定扩展点上已注册的扩展名称，按注册顺序排列；扩展点尚未声明时返回空列表 |

### 运行时状态

每次 PIE 或游戏会话结束时，uBotCore 将运行时状态写入 `<Project>/Saved/uBot/status.json`，覆盖上一次会话的记录。uBot Manager 读取其中的 `session` 和 `problems`，并在「上次运行」中显示。

| 字段 | 内容 |
| --- | --- |
| `session` | `kind`（`PIE` 或 `Game`）、开始和结束时间（协调世界时，UTC） |
| `packages` | 已安装的 uBot Package：名称、版本、是否启用 |
| `extensionPoints` | 已声明的扩展点和当时的实现数量 |
| `runtime` | 各 Package 发布的状态项：`id`、`label`、`value`、`detail`、`severity`（`ok`、`info`、`warning` 或 `error`） |
| `problems` | 各 Package 报告的问题：`id`、`package`、`severity`、`code`、`params` 和英文 `message` |

启用 `Validate Packages on Startup` 后，uBotCore 会在所有模块加载完成时检查一次 Package，将每个问题作为 `LogUBot` 警告写入日志，最后输出统计信息 `uBot packages: N installed, M enabled, K problem(s).`。

## 注意事项

- 蓝图只能查询已安装的 Package。仅在索引中登记而尚未安装的 Package 不会出现在结果中；查询结果的 `Available Versions`、`Index Versions` 等索引字段也为空。
- 查询结果来自启动时或点击面板刷新按钮时的扫描。通过 `.uproject` 修改 Package 启用状态后，需要重启编辑器才能生效。
- 扩展点和运行时状态项只能在 C++ 中声明和发布；蓝图只能查询扩展点及其已注册扩展的名称。用法见[在 C++ 中使用传感器与接口](/develop/cpp/)。
- uBot 面板仅提供状态查询，不执行安装、更新、启用或禁用操作。
- 找不到 uBot Manager 时，面板会弹出带下载链接的通知；可以在[设置项](/core/settings/)中指定 Manager 的可执行文件路径。
- `-run=UBotDocExport` 供维护者导出 API 参考数据，日常 Package 管理无需使用该命令。
