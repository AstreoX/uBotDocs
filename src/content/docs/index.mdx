## uBot 的特色

<ul class="home-features not-content">
  <li>
    <Icon name="star" size="1.5rem" />
    <h3>画面接近真机</h3>
    <p>Lumen 和 Nanite 渲染大场景，Fab 上的资产直接可用，相机拍到的画面接近真机。</p>
  </li>
  <li>
    <Icon name="puzzle" size="1.5rem" />
    <h3>装进原版 UE</h3>
    <p>uBot 是插件，装在原版 UE 5.5 上；uBot Manager 下载预编译包，不用编译。</p>
  </li>
  <li>
    <Icon name="pencil" size="1.5rem" />
    <h3>蓝图就能上手</h3>
    <p>搭场景、读传感器、处理 <code>cmd_vel</code> 都不用写 C++，文档里的节点图可以照着搭。</p>
  </li>
  <li>
    <Icon name="clock" size="1.5rem" />
    <h3>时间和数据有据可查</h3>
    <p>统一的仿真时钟支持固定步长、暂停和单步；每帧数据带序号、时间戳和状态码。</p>
  </li>
  <li>
    <Icon name="random" size="1.5rem" />
    <h3>环境会干扰感知</h3>
    <p>烟雾会截断激光雷达、改写深度、给相机画面染色。</p>
  </li>
  <li>
    <Icon name="link" size="1.5rem" />
    <h3>ROS 2 可选</h3>
    <p>话题、TF、<code>/clock</code> 和 <code>cmd_vel</code>；不用 ROS 2 时不必安装。</p>
  </li>
</ul>

## 从这里开始

[uBot Manager](/manager/) 是安装 uBot 的入口：它在 UE 工程里选择、安装和更新插件，启动时检查新版本，并处理插件之间的依赖。目前提供 Windows 版本，到 [Releases 页面](https://github.com/AstreoX/uBotManager/releases)下载安装包，安装步骤见[安装 uBot](/start/install/)。
