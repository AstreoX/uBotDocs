## uBot 的特色

<ul class="home-features not-content">
  <li>
    <Icon name="star" size="1.5rem" />
    <h3>高质量场景</h3>
    <p>结合 UE 的 Lumen 和 Nanite 渲染大规模场景，可使用 Fab 上的资产，相机画面接近真实。</p>
  </li>
  <li>
    <Icon name="puzzle" size="1.5rem" />
    <h3>原版 UE 即可使用</h3>
    <p>以插件形式安装到 UE 5.5 工程中；使用 uBot Manager 安装预编译包时，无需在本地编译编辑器模块。</p>
  </li>
  <li>
    <Icon name="pencil" size="1.5rem" />
    <h3>对新手友好</h3>
    <p>功能在蓝图中即可使用，无需编写 C++，文档提供对应的节点图。</p>
  </li>
  <li>
    <Icon name="clock" size="1.5rem" />
    <h3>统一的时间与数据</h3>
    <p>仿真时钟支持固定步长、暂停和单步；每帧数据携带序号、时间戳和状态码。</p>
  </li>
  <li>
    <Icon name="random" size="1.5rem" />
    <h3>模拟多种复杂真实环境</h3>
    <p>传感器可通过感知介质接口模拟烟雾等介质对测量的影响；环境效果的生成仍在规划中。</p>
  </li>
  <li>
    <Icon name="link" size="1.5rem" />
    <h3>可接入 ROS 2、MuJoCo 等</h3>
    <p>机器人算法可通过 ROS 2 交换仿真数据与控制指令；MuJoCo、PhysX 等物理引擎在规划中。</p>
  </li>
</ul>

## 从这里开始

[uBot Manager](/manager/) 是安装 uBot 的入口：管理器支持在 UE 工程中选择、安装和更新插件，启动时检查新版本，并处理插件之间的依赖。目前提供 Windows 版本，到 [Releases 页面](https://github.com/AstreoX/uBotManager/releases)下载安装包，安装步骤见[安装 uBot](/start/install/)。
