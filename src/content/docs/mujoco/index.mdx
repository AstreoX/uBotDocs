uBotMuJoCo 用原生 CPU MuJoCo 求解 UE 场景中的刚体、关节和接触。

<PackageStatus name="UBotMuJoCo" />

## 定位

uBotMuJoCo 将原生 CPU MuJoCo 接入 [uBotPhysics](/physics/)，求解交给它的刚体、关节和接触。Physics 负责模型实例、所有权、仿真时钟调度和位姿回写，MuJoCo 负责原生模型转换及求解。Chaos 继续模拟场景中的其他物体。

当前开发版面向 UE 5.5、Win64，使用 MuJoCo 4.0.0，依赖 uBotCore 和 uBotPhysics 的 0.2.0 开发线。它尚未发布，uBot Manager 暂不提供安装。

## 计划提供的能力

- **公共模型与原生扩展**：公共刚体、几何、惯性和关节描述归 Physics；MuJoCo 的 tendon、等式约束、actuator 等专属语义归 MuJoCo 扩展。运行时从这两部分构建原生模型。
- **模型资产与文件导入**：从 MJCF、URDF 和依赖资源生成模型资产及显示描述。导入报告说明支持范围和转换限制；修改导入物理数据后重新导入。
- **物理输入与状态**：接收执行器输入、广义力、外力和运动学目标，提供带时间戳的刚体及关节状态。机器人控制策略由外层组件实现。
- **连续固定步进**：默认步长为 0.002 秒，重力默认来自 UE World。超出每帧步数预算时暂停该后端并报告错误，显式重置后才能继续。
- **场景交互**：接收 Physics 导出的静态与运动学碰撞体。互相动态接触的物体应交给同一后端；跨后端保持单向运动学交互。

运行中的原生状态由 MuJoCo 维护，公共状态是只读输出。模型实例和场景更新采用事务；不支持保真迁移的更新会明确失败。重置和后端故障的范围是当前 World 的整个 MuJoCo 场景。

柔体、布料、外部 MuJoCo 动态库插件和用户回调不在首版范围内。URDF 支持以导入报告为准；凹三角网格不会被默认当作等价的凸碰撞体。

## 与现有插件的关系

- **uBotPhysics**：提供公共模型、绑定、后端扩展点、调度、场景几何和状态回写。MuJoCo 作为独立后端注册。
- **uBotCore**：复用仿真时钟、扩展注册、刚体状态源和[坐标约定](/concepts/coordinates-and-units/)。坐标转换直接使用中立契约。
- **uBotSensor**：继续从 UE 组件和已有[刚体状态源](/sensor/body-state/)读取数据；MuJoCo 不定义传感器测量模型。
- **uBotROS**：通过既有领域接口连接业务组件。ROS 协议、机器人控制策略和 MuJoCo 求解保持各自职责。

## 发布前可以先怎么做

- 使用已发布的 [uBotPhysics](/physics/) 了解绑定、所有权和场景几何的行为。
- 在原生 MuJoCo 中保存模型及其资源，并用固定输入建立对照结果。
- 开发线公共 C++ 契约与已发布的 Physics 0.1.x 不同，使用源码组合时统一重编译依赖模块；具体接口和开发用法见 [uBotMuJoCo 仓库](https://github.com/AstreoX/uBotMuJoCo)。
