物理无人机（`uBot Multirotor Dynamics`）支持速度、姿态、角速度和单电机四种指令，并根据最近接受的指令切换控制模式，在指令中断时执行设定动作。

## 快速用法

以下蓝图向无人机发送横滚角为 10° 的姿态指令，未显式指定推力，由内置控制器保持高度：

```blueprint
caption: 横滚 10° 的姿态指令（未显式指定推力，保持高度）
nodes:
  A: UUBotMultirotorLibrary.FindMultirotorMovement
  R: { ref: UKismetMathLibrary.MakeRotator, set: { Roll: 10 } }
  Q: UKismetMathLibrary.Conv_RotatorToQuaternion
  C: { ref: Make:FUBotAttitudeCommand, hideUnconnected: true }
  D: UUBotAttitudeCommandable.ApplyAttitudeCommand
wires:
  - A.ReturnValue -> D.self
  - R.ReturnValue -> Q.InRot
  - Q.ReturnValue -> C.Orientation
  - C.UBotAttitudeCommand -> D.Command
notes:
  C: 姿态是机体到世界的四元数。`Use Thrust` 为 false 时以 `Vertical Velocity Meters Per Second` 作为目标爬升率，0 表示保持高度。
```

## 步骤

<Steps>

1. **选无人机**

   用 `BP_UBotPhysicsDrone`（四种指令都接受）或 `BP_UBotBareAirframeDrone`（只接受角速度和单电机指令），见 [示例无人机与试飞关卡](/aerial/examples/)。

2. **取得 `Movement`**

   用 `Find Multirotor Movement` 取得 `Movement` 组件，通过该组件调用 `uBot|Actuation` 类别下的接口函数。

3. **发指令**

   四种指令分别对应一个接口函数；返回 `false` 表示该指令被拒绝，见下面的“注意事项”。

4. **结束控制时释放指令**

   对姿态、角速度指令调用 `Release Attitude Command`，对电机指令调用 `Release Motor Command`，无人机按 `Command Loss Action` 处理。

</Steps>

## 关键属性

最近一次被接受的指令决定当前控制模式，`Get Active Control Mode` 读取它。开始时无人机在 `Velocity` 模式下悬停：

| 模式 | 指令 | 内容 |
| --- | --- | --- |
| `Velocity` | `UBot Velocity Command` | 航向坐标系下的线速度与偏航角速度，按 `Velocity Limits` 截断；悬停和 `Land` 也使用此模式的设定值 |
| `Attitude` | `UBot Attitude Command` | 目标姿态（机体到世界）；`Use Yaw Rate` 时航向按偏航角速度转动 |
| `BodyRate` | `UBot Body Rate Command` | 机体坐标系目标角速度（rad/s，UE 旋向：+Z 向右偏航），不截断 |
| `Motor` | `UBot Motor Command` | 每个电机一个值，直接驱动电机，不经过飞行控制器 |

姿态和角速度指令支持两种推力控制方式：`Use Thrust` 为 true 时用 `Normalized Thrust`（0 到 1，最大总推力的比例），否则以 `Vertical Velocity Meters Per Second` 作为目标爬升率，0 表示保持高度。

电机指令的 `Type` 是 `Normalized`（0 到 1）或 `AngularVelocity`（rad/s）。`Normalized` 默认是推力比例：转速 = 最大转速 × √指令（`Motor Command Mapping` 为 `Thrust` 时）。数组元素数量必须等于电机数（`Get Motor Count`，默认机架 4 个），按机架的电机顺序：PX4 四旋翼 X 的电机序号为 0 右前、1 左后、2 左前、3 右后。

常用属性在 `Movement` 组件上，选中组件后，可在「Details」面板的「Dynamics」和「Multirotor」类别下查看：

| 属性 | 默认值 | 作用 |
| --- | --- | --- |
| `Accept Velocity Commands` 等四个 | 开 | 单独关闭某种指令，关闭后接口返回 `false` |
| `Command Loss Action` | `Hover` | 指令丢失时执行的动作 |
| `Command Timeout Seconds` | 0 s | 最近一条指令未更新的仿真时长超过此值时，判定指令丢失；0 表示禁用超时 |
| `Landing Speed Meters Per Second` | 0.7 m/s | `Land` 时的下降速度 |
| `Physics Rate Hz` | 1000 Hz | 每秒物理步数，范围 100 到 4000 Hz |

![物理无人机的组件树和 Movement 组件的 Details 面板：Dynamics 下有 Airframe 和 Control，Multirotor 下有 Physics Rate Hz](../../../assets/aerial/physics-movement.png)

`Command Loss Action` 有三个取值：

| 取值 | 效果 |
| --- | --- |
| `Hover`（默认） | 刹停并锁定位置，与 `Stop Motion` 相同 |
| `Land` | 保持水平位置并下降，接触地面后受碰撞约束而停止下降 |
| `CutMotors` | 所有电机指令置 0，无人机下落 |

默认机架是 1.5 kg、轴距 450 mm 的四旋翼 X，最大总推力约为重量的 1.92 倍；机架参数在 `Airframe` 上，改动在下一次 `Reset Flight` 生效；`Airframe` 在 `BeginPlay` 时检查一次。其余属性见 [uBot Multirotor Dynamics](/reference/ubotaerial/uubotmultirotordynamicscomponent/)。

## 输出与事件

- `Get Multirotor State` 返回真值状态（SI 单位、UE 世界轴），含转子转速和比力。
- `Get Last Motor Commands` 返回最近一次实际送给电机的指令。
- `Get Hover Motor Command` 按工程的重力返回悬停所需的归一化电机指令（推力比例），默认机架约 0.52。

可使用该返回值向四个电机发送悬停指令：

```blueprint
caption: 发送悬停电机指令（将 Make Array 扩展为 4 个输入，每个输入对应一个电机）
nodes:
  V: { var: Movement, class: UUBotMultirotorDynamicsComponent }
  H: UUBotMultirotorDynamicsComponent.GetHoverMotorCommand
  A: K2Node_MakeArray
  C: { ref: Make:FUBotMotorCommand, hideUnconnected: true, set: { Type: Normalized } }
  D: UUBotMotorCommandable.ApplyMotorCommand
wires:
  - V.Movement -> H.self
  - V.Movement -> D.self
  - H.ReturnValue -> A.[0]
  - A.Array -> C.Values
  - C.UBotMotorCommand -> D.Command
notes:
  A: 点击节点的「Add pin」将输入数量增加到 4，并将所有输入连接到 `Get Hover Motor Command` 的返回值。
```

## 注意事项

- 指令被拒绝（返回 `false`）有四种情况：对应的 `Accept … Commands` 属性已关闭，指令含非数值（NaN）或其他非有限值，姿态四元数的长度接近 0（平方长度小于 0.01），或电机值的个数与电机数不一致。裸机级不接受速度和姿态指令。
- `Stop Motion` 总是刹停并锁定位置，不受 `Command Loss Action` 影响：水平速度低于 0.05 m/s 后，锁定当前的水平位置和高度。
- 零速度指令仅要求速度收敛至零，不启用位置保持，因此不会修正风扰动造成的位置偏移。
- 通过 uBotROS 下发指令时，接收组件具有默认 0.5 s 的独立超时设置，各类组件的超时处理如下：
  - `uBot ROS Velocity Command` 调用 `Stop Motion`，刹停并锁定位置，不受 `Command Loss Action` 影响。
  - `uBot ROS Attitude Command` 和 `uBot ROS Motor Command` 调用 `Release Attitude Command` 或 `Release Motor Command`，由 `Command Loss Action` 处理。
