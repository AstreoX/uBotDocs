从 uBotAerial 0.1.1 起，无人机的 `Movement` 组件实现刚体状态源（Body State Source）接口，为根组件提供机体真值状态，传感器等状态使用者无需通过位姿差分估计速度。

| 内容 | 说明 |
| --- | --- |
| 位置、姿态、线速度、线加速度 | 与 `Get Multirotor State` 使用同一份最近物理步的状态，采用世界坐标轴和国际单位制（SI） |
| 角速度 | 世界坐标系，单位 rad/s。`Get Multirotor State` 里的角速度采用机体坐标系，刚体状态源会将其转换到世界坐标系 |
| 角加速度 | 世界坐标系，单位 rad/s²：该物理步内世界坐标系角速度的变化量除以步长。`Reset Flight` 和停止运动的 `Teleport Multirotor` 会同时清零角加速度和线加速度 |
| 时间戳 | 对应物理步的 uBot 仿真时间 |

接口 `IUBotBodyStateSource` 只能在 C++ 里使用，蓝图里没有对应的节点；蓝图可通过 `Get Multirotor State` 读取同一份多旋翼状态。

## 状态不是呈现的位姿

刚体状态对应最近一个物理步结束时刻，最多落后当前仿真时间一个步长；组件位姿则在每帧外推到当前仿真时间。因此，组件位姿与刚体状态中的位姿可能存在外推量，传感器从状态源读取真值速度和加速度，但位置与朝向仍取自组件变换。

## 提供哪个组件

- 状态源仅为根组件提供刚体状态，`VisualRoot`、旋翼和其他组件不作为独立刚体提供状态。
- 附着在这些组件下的传感器会沿附着关系向上查找根组件，并将中间连接视为刚性连接。计算传感器速度和加速度时，会计入其相对根组件的位置偏移（杠杆臂）。
- `Movement` 从注册时起声明对根组件的驱动所有权；在 `BeginPlay` 之前读取状态会返回失败。
- 从 uBotSensor 0.1.2 起，位姿、里程计和惯性测量单元（IMU）传感器读取该状态，见[读取刚体状态](/sensor/body-state/)。

## 不能绑定给物理后端

`Movement` 在提供状态的同时声明对机体的驱动所有权。因此，对无人机根组件执行物理后端的 `Bind` 操作会被拒绝，无论该操作发生在 `BeginPlay` 之前还是之后；无人机的动力学始终由 `Movement` 计算。
