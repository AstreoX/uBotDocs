绑定组件实现 uBotCore 的刚体状态源（Body State Source）接口，为已绑定组件提供后端最近一个物理步结束时的状态，传感器等状态使用者可以直接读取速度，无需通过位姿差分估计。

接口 `IUBotBodyStateSource` 从 uBotCore 0.1.3 起提供，属于实验性接口，仅支持 C++。状态使用 `FUBotBodyState` 结构体表示，采用 UE 世界坐标轴和国际单位制（SI）：

| 字段 | 内容 |
| --- | --- |
| `PositionMeters`、`Orientation` | 物体原点的位置（m）和物体到世界的姿态 |
| `LinearVelocityMetersPerSecond` | 世界坐标系线速度，m/s |
| `AngularVelocityRadiansPerSecond` | 世界坐标系角速度，rad/s，旋向与 UE 一致（+Z 向右偏航） |
| `LinearAccelerationMetersPerSecondSquared`、`AngularAccelerationRadiansPerSecondSquared` | 原点的运动学加速度（不含重力），世界坐标系，m/s² 和 rad/s²；只在 `bHasLinearAcceleration`、`bHasAngularAcceleration` 为真时有效 |
| `TimestampSeconds` | 后端最近一步结束的 uBot 仿真时间，不晚于当前仿真时间 |
| `Source` | 模拟这个物体的后端名（求解器没有设置时） |

## 提供与占有

- 状态源为组件提供状态时，同时声明对该组件的驱动所有权；其他绑定或状态源不能重复驱动同一组件，见[绑定与所有权](/physics/binding/)。
- 后端第一步之前，或组件没有绑定时，`GetBodyState` 返回 `false`。
- 后端在能力里声明 `Accelerations`（C++ 里是 `bAccelerations`），表示它的状态带线加速度和角加速度，见 [`UBot Physics Capabilities`](/reference/ubotphysics/structs/fubotphysicscapabilities/)。

## 在 C++ 里读取

`UBot::BodyState::GetNearestBodyState(Component, State)` 从指定组件开始，沿附着父级向上查找最近的、具有状态源的刚体，并返回该刚体的状态。传感器附着在绑定组件的子组件上时，可以通过此函数读取刚体的真值速度：

```cpp
#include "UBotBodyState.h"

void LogBodyVelocity(const USceneComponent* Component)
{
    FUBotBodyState State;
    if (UBot::BodyState::GetNearestBodyState(Component, State))
    {
        UE_LOG(LogTemp, Log, TEXT("%s: %.2f m/s"), *State.Source.ToString(), State.LinearVelocityMetersPerSecond.Size());
    }
}
```

C++ 里 `UUBotPhysicsSubsystem` 提供同样的查询：`FindBodyBackend` 给出模拟某个组件的后端，`GetBodyState` 给出绑定组件的状态。uBotPhysics 0.1.0 的蓝图节点里没有读取状态的节点；蓝图中可以通过 [`Get Body Physics Backend`](/reference/ubotphysics/uubotphysicslibrary/#GetBodyPhysicsBackend) 查询模拟指定组件的后端名称。

## 传感器怎么用

从 uBotSensor 0.1.2 起，位姿、里程计和惯性测量单元（IMU）传感器会自动检测并读取刚体状态，无需添加蓝图逻辑，见[读取刚体状态](/sensor/body-state/)。
