在自定义 C++ 模块中声明 uBot 依赖后，可以查找机器人上的传感器，通过共享接口读取数据和下发速度指令，也可以为自定义类实现这些接口。

## 步骤

### 调用传感器和接口

<Steps>

1. **添加模块依赖**

   在自定义模块的 `Build.cs` 中添加 `UBotCore` 和 `UBotSensor`。如果仅使用接口、时钟、标识（Identity）和坐标转换功能，只需添加 `UBotCore`。

   ```csharp
   PublicDependencyModuleNames.AddRange(new[]
   {
       "Core", "CoreUObject", "Engine", "UBotCore", "UBotSensor"
   });
   ```

   使用前需要在项目中启用这些插件。自定义插件还需要在 `.uplugin` 中声明对应依赖，见[编写自己的 uBot Package](/develop/package-authoring/)。

2. **查找传感器并调用接口**

   `UBot::Sensors::FindSensors` 返回 Actor 自身（如果它实现了接口）和所有实现 `IUBotSensor` 的组件，按组件顺序排列，不搜索子 Actor（Child Actor）。接口函数应通过 `IUBotSensor::Execute_*` 调用，以确保 C++ 和蓝图实现均能被正确执行。

   ```cpp
   #include "GameFramework/Actor.h"
   #include "UBotSensorInterface.h"

   void LogSensors(const AActor* Robot)
   {
       TArray<UObject*> Sensors;
       UBot::Sensors::FindSensors(Robot, Sensors);
       for (UObject* Sensor : Sensors)
       {
           const FString Id = IUBotSensor::Execute_GetSensorId(Sensor);
           const FName Type = IUBotSensor::Execute_GetSensorType(Sensor);   // 例如 IMU、Lidar2D
           const FUBotFrameHeader Header = IUBotSensor::Execute_GetLatestSensorHeader(Sensor);
           UE_LOG(LogTemp, Log, TEXT("%s (%s): sequence %lld"), *Id, *Type.ToString(), Header.Sequence);
       }
   }
   ```

3. **读取某一种传感器的数据**

   将 `FindSensors` 返回的对象转换为具体组件类型后，可以调用该组件的数据读取函数。`GetLatestIMUData` 返回最近一次样本，不会触发新的采样。

   ```cpp
   #include "UBotImuSensorComponent.h"

   void LogGyro(UObject* Sensor)
   {
       if (const UUBotImuSensorComponent* Imu = Cast<UUBotImuSensorComponent>(Sensor))
       {
           const FUBotImuSensorData Data = Imu->GetLatestIMUData();
           if (Data.Header.bValid)
           {
               UE_LOG(LogTemp, Log, TEXT("gyro (rad/s): %s"), *Data.AngularVelocityRadPerSecond.ToString());
           }
       }
   }
   ```

4. **下发速度指令**

   `UBot::Actuation::FindVelocityCommandable` 先检查 Actor 自身，再检查其组件；未找到实现对象时返回 `nullptr`。`FUBotVelocityCommand` 在机体坐标系下使用 UE 坐标轴（X 向前、Y 向右、Z 向上）：线速度单位 m/s，角速度单位 rad/s，+Z 为向右偏航。

   ```cpp
   #include "GameFramework/Actor.h"
   #include "UBotActuatorInterface.h"
   #include "UBotClock.h"

   bool DriveForward(AActor* Robot)
   {
       UObject* Drive = UBot::Actuation::FindVelocityCommandable(Robot);
       if (!Drive)
       {
           return false;
       }

       FUBotVelocityCommand Command;
       Command.LinearVelocityMetersPerSecond = FVector(0.5, 0.0, 0.0);
       Command.AngularVelocityRadiansPerSecond = FVector(0.0, 0.0, 0.2);
       Command.TimestampSeconds = UBot::Clock::GetSimTimeSeconds(Robot);
       Command.Source = TEXT("MyCode");   // 自由格式的来源标签
       return IUBotVelocityCommandable::Execute_ApplyVelocityCommand(Drive, Command);   // false 表示被拒绝
   }
   ```

   来自右手坐标系（例如 ROS 或 MuJoCo）的数据，需要先转换为 UE 坐标轴方向，再填写指令字段：线速度用 `UBot::RightHanded::VectorToUE`，角速度用 `AngularVelocityToUE`，见[坐标约定库](/core/conventions/)。

5. **读取仿真时间和机器人标识**

   所有 uBot 时间戳均通过 `UBot::Clock::GetSimTimeSeconds` 获取；该函数以 `UWorld::GetTimeSeconds()` 为基准，受暂停和时间膨胀影响。默认机器人标识取自 `AActor::GetName()`，与编辑器标签无关，打包后仍采用相同的解析规则。

   ```cpp
   #include "GameFramework/Actor.h"
   #include "UBotClock.h"
   #include "UBotIdentityComponent.h"

   void LogIdentity(const AActor* Robot)
   {
       const double Now = UBot::Clock::GetSimTimeSeconds(Robot);               // 秒；没有 World 时为 0
       const FString RobotId = UBot::Identity::ResolveRobotId(Robot);          // 没有 uBot Identity 组件时使用 Actor 名称
       const FString RobotNamespace = UBot::Identity::ResolveNamespace(Robot); // 没有组件时使用净化后的 Actor 名称
       const FString BaseFrame = UBot::Identity::ResolveBaseFrameId(Robot);    // 没有组件时是 base_link
       UE_LOG(LogTemp, Log, TEXT("t=%.3f %s ns=%s base=%s"), Now, *RobotId, *RobotNamespace, *BaseFrame);
   }
   ```

</Steps>

### 在 C++ 里实现接口

<Steps>

1. **实现传感器接口**

   组件实现 `IUBotSensor` 后，可由 `FindSensors` 发现；uBotROS 同样通过该接口发现传感器。接口函数声明为 `BlueprintNativeEvent`，C++ 实现需要重写对应的 `_Implementation` 函数。

   ```cpp
   // MyRangeSensorComponent.h（模块 MyRangeSensor）
   #pragma once

   #include "CoreMinimal.h"
   #include "Components/SceneComponent.h"
   #include "UBotSensorInterface.h"
   #include "UBotTypes.h"
   #include "MyRangeSensorComponent.generated.h"

   USTRUCT(BlueprintType)
   struct MYRANGESENSOR_API FMyRangeData
   {
       GENERATED_BODY()

       UPROPERTY(BlueprintReadOnly, Category = "MyRange")
       FUBotFrameHeader Header;

       UPROPERTY(BlueprintReadOnly, Category = "MyRange")
       float FieldOfViewRadians = 0.0f;

       UPROPERTY(BlueprintReadOnly, Category = "MyRange")
       float MinRangeMeters = 0.0f;

       UPROPERTY(BlueprintReadOnly, Category = "MyRange")
       float MaxRangeMeters = 0.0f;

       UPROPERTY(BlueprintReadOnly, Category = "MyRange")
       float RangeMeters = 0.0f;
   };

   DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FMyRangeEvent, const FMyRangeData&, Data);

   UCLASS(ClassGroup = (Custom), meta = (BlueprintSpawnableComponent))
   class MYRANGESENSOR_API UMyRangeSensorComponent : public USceneComponent, public IUBotSensor
   {
       GENERATED_BODY()

   public:
       UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "MyRange")
       FString SensorId = TEXT("range");

       UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "MyRange")
       FString FrameId = TEXT("range_link");

       UPROPERTY(BlueprintAssignable, Category = "MyRange")
       FMyRangeEvent OnRangeUpdated;

       /** 记录一个样本并触发 OnRangeUpdated。 */
       void PublishSample(float RangeMeters);

       //~ Begin IUBotSensor Interface
       virtual FString GetSensorId_Implementation() const override { return SensorId; }
       virtual FString GetSensorFrameId_Implementation() const override { return FrameId; }
       virtual FName GetSensorType_Implementation() const override { return TEXT("Range"); }
       virtual bool IsSensorRunning_Implementation() const override { return true; }
       virtual FUBotFrameHeader GetLatestSensorHeader_Implementation() const override { return LatestHeader; }
       virtual USceneComponent* GetSensorFrameComponent_Implementation() const override
       {
           return const_cast<UMyRangeSensorComponent*>(this);
       }
       //~ End IUBotSensor Interface

   private:
       UPROPERTY(Transient)
       FUBotFrameHeader LatestHeader;

       int64 Sequence = 0;
   };
   ```

   `PublishSample` 需要由自定义采样逻辑调用，固定频率采样方法见“注意事项”。帧头时间戳取自 uBot 时钟，样本序号由组件自行递增：

   ```cpp
   // MyRangeSensorComponent.cpp
   #include "MyRangeSensorComponent.h"
   #include "UBotClock.h"

   void UMyRangeSensorComponent::PublishSample(float RangeMeters)
   {
       FMyRangeData Data;
       Data.Header.SensorId = SensorId;
       Data.Header.FrameId = FrameId;
       Data.Header.Sequence = ++Sequence;
       Data.Header.TimestampSeconds = UBot::Clock::GetSimTimeSeconds(this);
       Data.Header.bValid = true;
       Data.Header.Status = EUBotSampleStatus::Valid;
       Data.RangeMeters = RangeMeters;

       LatestHeader = Data.Header;
       OnRangeUpdated.Broadcast(Data);
   }
   ```

2. **实现速度指令接口**

   `IUBotVelocityCommandable` 是独立的能力接口，不要求同时实现 `IUBotActuator`。返回 `false` 表示拒绝这条指令。

   ```cpp
   // MyDriveComponent.h
   #pragma once

   #include "CoreMinimal.h"
   #include "Components/ActorComponent.h"
   #include "UBotActuatorInterface.h"
   #include "MyDriveComponent.generated.h"

   UCLASS(ClassGroup = (Custom), meta = (BlueprintSpawnableComponent))
   class UMyDriveComponent : public UActorComponent, public IUBotVelocityCommandable
   {
       GENERATED_BODY()

   public:
       virtual bool ApplyVelocityCommand_Implementation(const FUBotVelocityCommand& Command) override;
       virtual void StopMotion_Implementation() override;

   private:
       FVector TargetLinear = FVector::ZeroVector;
       FVector TargetAngular = FVector::ZeroVector;
   };

   // MyDriveComponent.cpp
   #include "MyDriveComponent.h"

   bool UMyDriveComponent::ApplyVelocityCommand_Implementation(const FUBotVelocityCommand& Command)
   {
       const FVector& Linear = Command.LinearVelocityMetersPerSecond;      // 机体系，UE 轴，m/s
       const FVector& Angular = Command.AngularVelocityRadiansPerSecond;   // rad/s，+Z 向右偏航
       if (Linear.ContainsNaN() || Angular.ContainsNaN())
       {
           return false;
       }
       TargetLinear = Linear;
       TargetAngular = Angular;
       return true;
   }

   void UMyDriveComponent::StopMotion_Implementation()
   {
       TargetLinear = FVector::ZeroVector;
       TargetAngular = FVector::ZeroVector;
   }
   ```

   控制器、油门和转向映射由接口实现方负责，uBotROS 本身不提供这些控制逻辑。

</Steps>

### 在蓝图里实现接口

<Steps>

1. **打开「Class Settings」**

   打开蓝图 Actor 或蓝图组件，点击工具栏的「Class Settings」。

2. **添加接口**

   在「Details」面板的「Interfaces」区域点击「Add」，选择 `UBot Velocity Commandable`。若要实现传感器接口，则选择 `UBot Sensor`。

3. **实现函数**

   在「My Blueprint」面板的「Interfaces」区域，双击有返回值的函数（如 `Apply Velocity Command`）并编写实现。没有返回值的函数（如 `Stop Motion`）需要在事件图中右键添加对应事件。

4. **编译并保存**

   编译并保存后，C++ 可通过 `FindVelocityCommandable` 查找实现对象，并通过 `Execute_ApplyVelocityCommand` 调用蓝图实现。

</Steps>

| `IUBotActuator` | `UBotActuatorInterface.h` | `GetActuatorId`、`GetActuatorType`、`IsActuatorReady` |
| `IUBotVelocityCommandable` | `UBotActuatorInterface.h` | `ApplyVelocityCommand`、`StopMotion` |

| `UBot::Sensors::FindSensors` | `UBotSensorInterface.h` | Actor 自身（如果实现了接口）加上所有实现 `IUBotSensor` 的组件 |
| `UBot::Actuation::FindVelocityCommandable` | `UBotActuatorInterface.h` | 第一个实现 `IUBotVelocityCommandable` 的对象，未找到时为 `nullptr` |
| `UBot::Interfaces::FindImplementers`、`FindFirstImplementer` | `UBotSensorInterface.h` | 上述查找函数的通用版本，参数是接口的 `UClass`，如 `UUBotActuator::StaticClass()` |
| `UBot::Clock::GetSimTimeSeconds` | `UBotClock.h` | 仿真时间，单位秒 |
| `FUBotExtensionRegistry` | `UBotExtensionRegistry.h` | 扩展点：`RegisterExtensionPoint` 声明，`RegisterExtension` 注册，`GetExtensions` 查询；例子见[为自定义传感器添加 ROS 发布器](/develop/ros-publisher/) |
| `FUBotRuntimeStatus` | `UBotRuntimeStatus.h` | 运行状态：`SetItem` 发布一个状态项，`ReportProblem` 报告一个问题，显示在 uBot 面板的「Runtime」和「Problems」分区，见 [Package 查询与编辑器面板](/core/packages/) |
| `UBot::Identity::Find`、`ResolveRobotId`、`ResolveNamespace`、`ResolveBaseFrameId`、`ResolveBaseComponent` | `UBotIdentityComponent.h` | 与 uBot Identity 组件相同的解析规则，Actor 未添加该组件时回退到默认值 |

| `UBot::RightHanded::PositionFromUE`、`VectorFromUE`、`AngularVelocityFromUE`、`RotationFromUE`、`TransformFromUE`、`YawFromUE` | `UBotRightHandedConventions.h` | UE（左手系，厘米）到右手系（FLU，国际单位制）的换算，反方向是对应的 `…ToUE`。纯数学函数，不含 ROS 或引擎的类型，规则见[坐标系与单位](/concepts/coordinates-and-units/) |

## 输出与事件

- `Execute_*` 返回被调用接口函数的返回值。`Execute_ApplyVelocityCommand` 返回 `false` 表示指令被拒绝（目标尚未就绪、数值无效等）。
- `Execute_GetLatestSensorHeader` 返回最近一次采样的帧头，不会触发新的采样。
- 传感器事件通过 `AddDynamic` 绑定，处理函数必须是 `UFUNCTION()`：

```cpp
// 在头文件中声明：UFUNCTION() void HandleImu(const FUBotImuSensorData& Data);
void UMyReceiver::Bind(UUBotImuSensorComponent* Imu)
{
    Imu->OnImuDataUpdated.AddDynamic(this, &UMyReceiver::HandleImu);
}
```

## 注意事项

- 应通过 `Execute_*` 调用接口函数。将对象 `Cast` 为 `IUBotSensor*` 后直接调用函数，无法执行蓝图提供的接口实现。
- `FindSensors` 返回的对象一定实现了接口。对其他对象调用接口前，应先通过 `Object->Implements<UUBotSensor>()` 检查。
- 查找函数只搜索 Actor 自身和它的组件，不搜索子 Actor。
- uBotCore 0.1.3 起，旧的 `UBot::Ros` 命名空间（`UBotRosConventions.h`）已弃用，其中的坐标轴转换函数转发到 `UBot::RightHanded`，结果相同。
- ROS 专属的函数（`CameraLinkToOpticalRotation`、`OpticalFrameSuffix`、`SecondsToRosTime`、`RosTimeToSeconds`、`SanitizeRosName`）已迁移到 uBotROS 的 `UBot::ROSConventions`（`UBotROSConventionHelpers.h`），调用这些函数的模块需要依赖 `UBotROS`。
- 按固定频率采样时，应使用 `FUBotSampleScheduler`（`UBotSampleScheduler.h`）。循环定时器在单帧耗时较长时可能于同一帧触发多次，生成重复时间戳，见[仿真时钟与采样调度](/concepts/clock-and-scheduling/)。
