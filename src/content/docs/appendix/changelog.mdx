## uBotCore

### 0.1.2

- 新增两个接口：`UBot Attitude Commandable` 接受姿态指令和角速度指令，`UBot Motor Commandable` 接受单个电机指令，供飞行器实现。新增三种指令结构体：`UBot Attitude Command`、`UBot Body Rate Command` 和 `UBot Motor Command`，见[插件之间怎么对接](/concepts/interfaces/)。
- 约定：会倾斜的接收者（比如多旋翼）按航向坐标系解释速度指令，X、Y 沿当前航向，Z 朝上。
- 新增 commandlet `UBotDocExport`，把插件的蓝图 API 导出成文档站使用的 `api.json`。这是给维护者用的，使用者用不到。
- 包索引新增 uBotROS 0.1.2 和 uBotAerial 0.1.0 的条目，并列出规划中的 uBotMuJoCo。
- 提供 UE 5.5 Win64 的预编译包。

### 0.1.1

- 插件图标，以及编辑器里 uBot 面板的标签页、「Window」菜单项和状态栏入口，换成 uBot 标志。
- 包索引的版本条目可以带 `binaries`，写明预编译包的下载地址、校验值和大小。uBot Manager 用它安装预编译包，UE 本身忽略这个字段。
- 提供 UE 5.5 Win64 的预编译包。

### 0.1.0

首个版本。

- 帧头 `UBot Frame Header` 和状态码 `EUBot Sample Status`，见[帧头与采样状态](/concepts/frame-header/)。
- 仿真时钟：读取仿真时间，固定步长，暂停、恢复和单步，见[仿真时钟与采样调度](/concepts/clock-and-scheduling/)。
- UE 与 ROS（REP-103）之间的坐标、单位和时间转换节点，见[坐标系与单位](/concepts/coordinates-and-units/)。
- 采样调度器：每次轮询最多触发一次，不会在同一帧里重复采样。
- 四个接口：`UBot Sensor`、`UBot Actuator`、`UBot Velocity Commandable` 和 `UBot Perception Medium`，见[插件之间怎么对接](/concepts/interfaces/)。
- `uBot Identity` 组件，给机器人命名，见[标识与命名](/concepts/identity/)。
- Package 管理的基础：包索引（格式 2）、依赖和版本校验、运行时状态（`Saved/uBot/status.json`）、编辑器里的 uBot 面板（「Window > uBot」）、扩展点，以及命令行 `-run=UBotPackage`。安装、更新、启用和卸载由 uBot Manager 完成。

## uBotSensor

### 0.1.1

- 插件图标换成 uBot 标志。
- 提供 UE 5.5 Win64 的预编译包。

### 0.1.0

首个版本，由旧插件 `AgentSensorCore` 0.5.0 重命名迁移而来，建立在 uBotCore 之上。

- 七种传感器组件：位姿、里程计、IMU、2D 激光雷达、3D 激光雷达、RGB 相机和深度相机，另有相机采集协调器。组件的显示名从 `Agent …` 改为 `uBot …`，比如 `uBot IMU Sensor`。
- 烟雾等感知介质通过 uBotCore 的 `UBot Perception Medium` 接口接入，原来用 Actor 标签的烟雾 Actor 仍然有效。
- 采样改为由组件的 tick 和采样调度器驱动：每个 world tick 最多一个样本，时间戳取仿真时间。IMU 和里程计不再因为同一帧里的重复样本报告 `Invalid Delta Time`。
- 新增 `Get Dropped Sample Count`，统计因帧率太低而跳过的采样时刻。
- 2D 和 3D 激光雷达的帧新增强度（`Get Intensities`，0 到 255）。
- 所有传感器实现 `UBot Sensor` 接口。
- 旧插件的蓝图和关卡在切换到 uBotSensor 后可以加载（CoreRedirects），详见[从旧插件迁移](/develop/migration/)。

## uBotROS

### 0.1.2

- 新增 `uBot ROS Attitude Command` 组件：订阅 `/<namespace>/cmd_attitude`（`mavros_msgs/msg/AttitudeTarget`），把姿态指令或角速度指令交给实现了 `UBot Attitude Commandable` 的对象。
- 新增 `uBot ROS Motor Command` 组件：订阅 `/<namespace>/cmd_motors`（`actuator_msgs/msg/Actuators`），把电机指令交给实现了 `UBot Motor Commandable` 的对象。
- 两个组件的目标、超时（`Command Timeout Seconds`，默认 0.5 s）和错误事件与 `uBot ROS Velocity Command` 相同。超过超时没有新指令时，目标收到一次释放，由飞行器自己兜底，比如悬停。用法见[从 ROS 2 发飞行指令](/ros/flight-commands/)。
- ROS 桥新增运行依赖 `mavros_msgs` 和 `actuator_msgs`，在 ROS 一侧安装 `ros-humble-mavros-msgs` 和 `ros-humble-actuator-msgs`。
- 依赖改为 uBotCore 0.1.2 或更新的 0.1.x。
- 与 ROS 桥握手时报告的 UE 端版本现在是 `uBot UE 0.1.2`。
- 提供 UE 5.5 Win64 的预编译包。

### 0.1.1

- 插件图标换成 uBot 标志。
- 与 ROS 桥握手时报告的 UE 端版本跟随插件版本，现在是 `uBot UE 0.1.1`。
- 提供 UE 5.5 Win64 的预编译包。

### 0.1.0

首个版本，取代旧插件 `AgentSensorROSBridge` 等，建立在 uBotCore 和 uBotSensor 之上。

- `uBot ROS Sensor Bridge` 组件：发现 Actor 上的 uBot 传感器并发布到 ROS 2，同时发布静态 TF、动态 TF（`odom → base_link`）和相机的光学坐标系。
- `/clock`：发布 uBot 的仿真时间。
- `uBot ROS Velocity Command` 组件：把 `cmd_vel` 交给实现了 `UBot Velocity Commandable` 的对象，带超时和限速。
- 随插件附带 ROS 2 桥 `ubot_ros_bridge`，UE 经一条 TCP 连接与它通信。UE 一侧不再依赖 TempoROS 和 rclcpp。
- 桥的连接状态显示在编辑器的 uBot 面板和 uBot Manager 里。
- 项目设置保存在 `Config/DefaultUBotROS.ini`。
- 相对旧版有几处有意的修正，比如角速度符号、`LaserScan` 的镜像、`PointCloud2` 增加 `intensity` 字段、相机图像改用光学坐标系、里程计不再发布静态 TF。
- 默认的命名空间来自 `uBot Identity`，不再是固定的 `robot`。

## uBotAerial

### 0.1.0

首个版本，建立在 uBotCore 0.1.2 之上，另需引擎插件 Enhanced Input。

- 三个示例无人机蓝图，在插件内容的 `/UBotAerial/Examples/` 下，由插件的组件拼成：`BP_UBotNavigationDrone`（导航、规划、感知，接收速度和偏航角速度）、`BP_UBotPhysicsDrone`（需要真实动力学，接收速度、姿态、角速度和单电机）和 `BP_UBotBareAirframeDrone`（研究飞控，接收角速度和单电机）。见[示例无人机与试飞关卡](/aerial/examples/)。
- 演示地图 `/UBotAerial/Maps/L_UBotAerialDemo`，三架示例无人机并排放在里面。
- `uBot Simple Flight`：导航级飞行模型，速度按一阶响应逼近指令，见[用速度指令飞导航无人机](/aerial/simple-flight/)。
- `uBot Multirotor Dynamics`：物理级飞行模型，多旋翼刚体动力学，带内置的串级飞控 `uBot Cascaded Flight Controller`，见[物理无人机的指令与控制模式](/aerial/dynamics/)。自己写飞控时继承 `uBot Flight Controller`，见[自己写飞控](/aerial/flight-controller/)。
- `uBot Rotor` 桨叶组件，随电机转速旋转。
- `uBot Multirotor Manual Input`：键盘和手柄手动飞行，见[键盘和手柄手动飞行](/aerial/manual-flight/)。
- 风：关卡里放置的 `uBot Wind` 和汇总所有风源的 `uBot Wind Subsystem`，见[风](/aerial/wind/)。
- 无人机会撞上地面、墙和其他物体，见[碰撞](/aerial/collision/)。
- 无人机通过 uBotCore 的速度、姿态和电机指令接口接收指令，uBotROS 0.1.2 的指令组件可以直接驱动它，见[插件之间怎么对接](/concepts/interfaces/)。
- 示例无人机的模型来自 Fab 上的 Animated Drone（CC BY 4.0）。
- 提供 UE 5.5 Win64 的预编译包。

## uBot Manager

### 0.1.0

首个版本。

- 在 UE 5.5 工程里安装、更新、降级、启用、禁用和卸载 Package，自动处理依赖。
- 依赖图、问题列表和快速修复。
- 组合（Recipe）：一次装好一组 Package，也可以把当前项目的 Package 存成自己的组合。
- 预编译包安装：下载、校验、解压，不需要 git 和编译。
- 命令行 `ubot`，包括 `ubot package`，用来制作预编译包。
- 界面支持简体中文和英文，深色和浅色主题。安装包按当前用户安装，没有代码签名。
