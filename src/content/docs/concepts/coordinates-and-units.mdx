## UE 的坐标系和单位

UE 世界坐标和 `Transform` 的平移分量以厘米为单位，蓝图中的旋转类型 `Rotator` 以度为单位。偏航是绕 Z 轴的旋转，其正方向为向右转。

## uBot 输出用的单位

uBot 公共接口默认采用国际单位制（SI，International System of Units），包括米、秒和弧度。名称中包含 `Centimeters` 或 `Degrees` 的属性除外，应按名称标明的单位解释。

| 量 | 单位 |
| --- | --- |
| 位置、距离 | m |
| 速度 | m/s |
| 线加速度 | m/s² |
| 角度 | rad |
| 角速度 | rad/s |
| 时间 | s |
| 世界变换的平移分量 | cm，保留 UE 原始单位 |

属性名称会标明单位，例如 `Position Meters`、`Angular Velocity Rad Per Second`、`Linear Acceleration Meters Per Second Squared`。此处的世界变换指点云帧、图像帧和 2D 激光雷达帧中的 `Sensor Transform World`。

长度数值转换为米后，坐标轴仍遵循 UE 约定：X 向前、Y 向右、Z 向上。uBotSensor 输出数据时不改变坐标轴方向；坐标转换由对外交换数据的模块执行，例如 uBotROS 在发布 ROS 消息时执行转换。

惯性测量单元（IMU）的线加速度输出表示比力（specific force）。在 World 默认重力加速度为 −980 cm/s² 时，静止传感器的比力大小约为 9.8 m/s²，方向为世界竖直向上，并以传感器坐标系表示。

## 右手系（FLU）的坐标系

uBot 的外部右手坐标约定为 X 向前、Y 向左、Z 向上，长度单位为米，简称 FLU（Forward-Left-Up）。该约定符合 ROS REP-103，也适用于模型 X 轴朝前、Z 轴朝上的 MuJoCo 等右手坐标系引擎。

从 UE 转换到 FLU 时，需要沿 Y 轴反向的镜像映射，并按数据类型换算长度单位。坐标分量映射具有自逆性：`Right-Handed To UE …` 与 `UE To Right-Handed …` 使用相同的分量映射，长度单位的换算方向相反。

uBotCore 使用与协议无关的名称提供这组转换：C++ 命名空间为 `UBot::RightHanded`，蓝图节点为 `UE To Right-Handed …` 和 `Right-Handed To UE …`。

## 转换规则

镜像时，位置、速度等极向量（polar vector）仅翻转 Y 分量，角速度、力矩等轴向量（axial vector）翻转 X 和 Z 分量。下表是 UE 到右手系的规则：

| 量 | UE → 右手系 | 蓝图节点 |
| --- | --- | --- |
| 位置 | `(x, -y, z) / 100` | `UE To Right-Handed Position` |
| 线速度、加速度 | `(x, -y, z)` | `UE To Right-Handed Vector` |
| 角速度、力矩 | `(-x, y, -z)` | `UE To Right-Handed Angular Velocity` |
| 旋转 | `(-x, y, -z, w)` | `UE To Right-Handed Rotation` |
| 变换 | 旋转镜像，平移换算 | `UE To Right-Handed Transform` |
| 航向、扫描角 | `右手系 = -UE` | `UE To Right-Handed Yaw` |

补充说明：

- 位置从厘米转换为米。线速度、加速度的分量映射也适用于已经以米表示的点坐标，且不再换算单位。
- 旋转是四元数 `(x, y, z, w)`，转换后归一化。
- 变换的平移从厘米转换为米，转换时丢弃缩放，输出缩放为 1。
- 航向角和扫描角以 rad 表示，偏航角速度以 rad/s 表示；对应节点仅改变符号，保留输入单位。

反向转换使用对应的 `Right-Handed To UE …` 节点。例如，UE 中向右偏航的正 Z 角速度，转换到 FLU 后为负 Z 角速度。

在 uBotCore 0.1.2 及更早版本中，这些节点名为 `UE To ROS …` 和 `ROS To UE …`。0.1.3 起它们已弃用，结果与新节点相同，见[坐标约定库](/core/conventions/)。

## ROS 专属的部分

以下转换属于 ROS 专用约定。从 uBotCore 0.1.3 起，对应实现由 uBotROS 提供；蓝图节点位于类别 `uBot|ROS|Conventions` 下，名称保持不变：

| 内容 | 规则 | 蓝图节点 |
| --- | --- | --- |
| 相机光学系 | z 前、x 右、y 下；光学坐标系标识（frame id）由相机 frame id 追加后缀 `_optical` | `Camera Link To Optical Rotation`、`Get Optical Frame Suffix` |
| 时间 | 以秒表示的时间与 `(sec, nanosec)` 双向转换；秒数为负数或非有限值时返回 `(0, 0)` | `Seconds To ROS Time`、`ROS Time To Seconds` |
| ROS 名称 | 只保留字母、数字和下划线，规则见[标识与命名](/concepts/identity/) | `Sanitize ROS Name` |
| 6×6 协方差 | 部分元素变号 | 无节点 |

协方差第 r 行第 c 列的元素，在 r 和 c（索引从 0 开始）中恰有一个为奇数时变号。该转换没有蓝图节点，由 uBotROS 在发布里程计（Odometry）消息时自动执行。
