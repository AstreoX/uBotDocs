uBotSensor 给 Actor 装上仿真传感器，在蓝图里读取位姿、里程计、IMU、激光雷达和相机的数据，不需要写代码。

## 能做什么

每种传感器都是一个组件，在「Components」面板里添加即可。点传感器名进入它的页面：

| 传感器 | 主要输出 | 事件 | 默认频率 |
| --- | --- | --- | --- |
| [位姿传感器](/sensor/pose/) | 位置（m）、姿态四元数、可选线速度和角速度 | `On Pose Data Updated` | 30 Hz |
| [里程计](/sensor/odometry/) | 相对起点的位姿（m）、本地坐标系下的速度、协方差 | `On Odometry Data Updated` | 30 Hz |
| [IMU 传感器](/sensor/imu/) | 姿态四元数、角速度（rad/s）、比力（m/s²）、方差 | `On Imu Data Updated` | 100 Hz |
| [2D 激光雷达](/sensor/lidar-2d/) | 每个角度的距离（m）、命中标志、强度 | `On 2DLidar Frame Ready` | 10 Hz |
| [3D 激光雷达](/sensor/lidar-3d/) | 命中点（m）、环号、强度 | `On 3DLidar Frame Ready` | 10 Hz |
| [RGB 相机](/sensor/rgb-camera/) | `BGRA8` 图像，像素按需读回 CPU | `On Image Frame Ready` | 30 Hz |
| [深度相机](/sensor/depth-camera/) | `Depth32FC1` 深度图（m），0 表示无效 | `On Image Frame Ready` | 30 Hz |

所有传感器共用同一套启动、停止、通用事件和帧头，见[传感器通用用法](/sensor/basics/)。另有两项功能：[相机采集协调器](/sensor/capture-coordinator/)让多个相机在同一时刻采集，[感知介质](/sensor/medium/)让烟雾干扰激光雷达和相机。

## 依赖与安装

<PackageStatus name="UBotSensor" />

用 [uBot Manager](/manager/) 安装，依赖会一并装好。安装后传感器组件在「Add」菜单的「uBot」分类下，显示名形如 `uBot IMU Sensor`。

插件本身不含 ROS 代码，输出是 UE 原生的结构体和对象，单位是米、秒、弧度。把数据发布到 ROS 用 [uBotROS](/ros/)。

## 组件一览

`Get Sensor Type` 返回的类型键用来在 C++ 或蓝图里区分传感器：

| 组件 | 类型键 | 作用 |
| --- | --- | --- |
| [`uBot Pose Sensor`](/reference/ubotsensor/uubotposesensorcomponent/) | `Pose` | 输出组件自身的位姿 |
| [`uBot Odometry Sensor`](/reference/ubotsensor/uubotodometrysensorcomponent/) | `Odometry` | 输出被跟踪组件相对起点的位姿和速度 |
| [`uBot IMU Sensor`](/reference/ubotsensor/uubotimusensorcomponent/) | `IMU` | 输出姿态、角速度和比力 |
| [`uBot 2D LiDAR Sensor`](/reference/ubotsensor/uubot2dlidarsensorcomponent/) | `Lidar2D` | 在本地 XY 平面上扫描 |
| [`uBot 3D LiDAR Sensor`](/reference/ubotsensor/uubot3dlidarsensorcomponent/) | `Lidar3D` | 按视场和线数扫描，输出点云 |
| [`uBot RGB Camera Sensor`](/reference/ubotsensor/uubotrgbcamerasensorcomponent/) | `RGBCamera` | 渲染彩色图像 |
| [`uBot Depth Camera Sensor`](/reference/ubotsensor/uubotdepthcamerasensorcomponent/) | `DepthCamera` | 渲染深度图像 |
| [`uBot Camera Capture Coordinator`](/reference/ubotsensor/uubotcameracapturecoordinatorcomponent/) | | 让同组相机统一触发，共用序号和时间戳 |
| [`UBot Sensor Component`](/reference/ubotsensor/uubotsensorcomponent/) | | 所有传感器的基类，共有的节点和属性 |
| [`UBot 2DLidar Frame`](/reference/ubotsensor/uubot2dlidarframe/) | | 一次 2D 扫描的数据 |
| [`UBot Point Cloud Frame`](/reference/ubotsensor/uubotpointcloudframe/) | | 一次 3D 扫描的点云 |
| [`UBot Image Frame`](/reference/ubotsensor/uubotimageframe/) | | 一次相机采集的图像 |
