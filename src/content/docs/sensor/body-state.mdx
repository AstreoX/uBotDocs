当机体具有刚体状态源（Body State Source）时，位姿、里程计和 IMU 传感器直接读取该状态源提供的速度和加速度，无需通过位姿差分计算这些运动量，这一行为从 uBotSensor 0.1.2 起提供。

刚体状态源由插件通过 C++ 实现，例如无人机的 `Movement` 组件（见[无人机的刚体状态](/aerial/body-state/)）和物理后端的绑定组件。传感器会自动检测可用的状态源，无需在蓝图中额外配置。

| 传感器 | 状态模式下读取的刚体状态数据 | 仍通过组件变换确定的数据或判定 |
| --- | --- | --- |
| [位姿传感器](/sensor/pose/) | 线速度和角速度，首个样本即可提供 | 位置、姿态 |
| [里程计](/sensor/odometry/) | 本地坐标系下的线速度和角速度 | 相对起点的位姿、协方差 |
| [IMU 传感器](/sensor/imu/) | 姿态、角速度、比力，三者属于同一时刻 | 瞬移判断、样本间隔判断 |

## 什么时候读状态

传感器在每次采样时重新检测状态源，以处理状态源的出现或消失：

1. 从传感器组件沿附着链向上查找，选择距离最近且由状态源驱动的刚体。里程计以被跟踪组件为查找起点。
2. 找到状态源且 `Use Body State` 已开启（默认开启）时，传感器使用**状态模式**；否则使用**差分模式**。位姿传感器还要求 `Reference Frame` 是 `World`。
3. 差分模式与 0.1.1 的算法相同，没有状态源的场景行为不变。

刚体到传感器之间的部分按刚性连接处理：传感器相对刚体的位置（杠杆臂）取当前的组件变换，IMU 和里程计的速度、加速度已换算到传感器所在的点。如果传感器安装在相对刚体运动的部件上（例如云台），应关闭 `Use Body State`。

## 状态的年龄

- 帧头的时间戳始终是取样时刻（仿真时间），而非刚体状态对应的时刻。
- 状态是最近一个物理步的结果，传感器直接使用，不外推。取样时刻减去状态时刻是状态的**年龄**，通常小于一个物理步的时间间隔。
- 年龄超出 [-1e-6 s, 上限] 时，IMU 和里程计将样本标记为 `Invalid Delta Time`，并重置用于后续计算的历史状态。IMU 的上限是 `Max Sample Delta Seconds`，里程计的是 `Maximum Valid Delta Seconds`。位姿传感器不检查年龄。

| 节点 | 说明 |
| --- | --- |
| `Use Body State` | 属性，默认 true；关闭后始终使用差分模式 |
| `Is Using Body State` | 最新样本是否取自状态源。状态模式下为 true，包括处于预热阶段（`Warming Up`）或 `Invalid Delta Time` 状态的样本；差分模式，以及刚体由状态源驱动但尚未提供状态时为 false |
| `Get Body State Age Seconds` | 最新样本的年龄，单位 s；没有用到状态时为 0 |

## 暖机与模式切换

- IMU 在状态模式下的首个样本为 `Warming Up`，从第二个样本开始有效；在差分模式下，前两个样本均为 `Warming Up`。状态不带加速度时，IMU 用相邻两个状态时刻的速度变化推算，状态时间尚未推进时，沿用上一次计算得到的加速度。
- 里程计在两种模式下的首个样本均为 `Warming Up`。
- 相邻两个样本的模式不同（状态源出现或消失，或 `Use Body State` 设置发生变化），IMU 重置历史，里程计重新建立用于差分计算的历史样本，保留原有起点；切换后的当前样本为 `Warming Up`。
- 刚体由状态源驱动但尚未提供状态时（例如无人机尚未执行 `BeginPlay`），IMU 和里程计给出 `Warming Up`，位姿传感器给出有效位姿但没有速度。
- 噪声、偏置随机游走、低通滤波和限幅作用在真值上，两种模式共用相同的后处理流程。

## 与 0.1.1 的区别

- 没有状态源时，输出与 0.1.1 相同，只有角速度例外：相邻两个样本间转角小于 2e-4 rad 时，0.1.1 将旋转轴错误地报告为 X 轴，现在按真实转轴计算。
- 有状态源时，速度和加速度是状态给出的真值，不是对位姿的差分。
