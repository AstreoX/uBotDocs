根据仿真任务选择插件组合（Recipe），并通过 uBot Manager 安装组合中的插件及其依赖。

## 组合一览

<RecipeTable />

带“规划中”标记的组合包含还没有发布的插件。uBot Manager 将这些组合显示为灰色；由于尚未发布的插件无法勾选，目前只能安装其中已发布的部分。

## 各组合适合什么场景

| 组合 | 适用场景 | 后续操作 |
| --- | --- | --- |
| 仅传感器 | 只在蓝图里读传感器数据，不需要准备 ROS 2 端 | 先看[五分钟上手](/start/quickstart/)，再读 [uBotSensor 手册](/sensor/) |
| ROS 2 传感器 | ROS 2 里的算法需要仿真传感器的输入：位姿、IMU、里程计、激光雷达、相机，以及 TF 和 `/clock` | 先[准备 ROS 2 端](/ros/ros2-setup/)，再[发布传感器数据](/ros/publish-sensors/) |
| ROS 地面机器人 | 差速或阿克曼地面车辆，接入 Nav2 和同步定位与建图（SLAM） | 要用到 [uBotVehicles](/vehicles/) |
| 大模型无人机 | 多旋翼无人机，由大语言模型通过模型上下文协议（MCP）控制 | 要用到 [uBotAerial](/aerial/) 和 [uBotMCP](/mcp/) |
| 烟雾作战演示 | 炮塔、弹药等作战内容，加上烟雾对传感器的干扰 | 要用到 [uBotEnvironment](/environment/) 和 [uBotCombat](/combat/) |
| 自定义 | 以 uBotCore 为基础，按需选择其他插件 | 在「Package」视图里逐个安装，见[安装 uBot](/start/install/) |

所有组合都包含 uBotCore。ROS 2 传感器和 ROS 地面机器人两个组合还需要 ROS 2 端的 `ubot_ros_bridge`：该程序在 ROS 2 端运行，uBot Manager 的「环境要求」会列出该程序，但不会检查其安装或运行状态。

## 用 uBot Manager 一次装好一个组合

<Steps>

1. **打开工程**

   启动 uBot Manager，打开工程的 `.uproject`，见[安装 uBot](/start/install/)。

2. **选组合**

   点击标题栏的「Recipe」，在「应用 Recipe」里选一个组合。「Package」列表里，`UBotCore` 固定勾选，可根据需要增加或取消其他 Package。

3. **检查环境**

   「环境要求」会检查 Visual Studio 2022 和 Git。如果全部插件均采用预编译包安装，则不需要这两项工具。

4. **查看并应用**

   点击「查看更改…」，在「应用更改」对话框里确认步骤，再点击「应用」。

</Steps>

应用组合会安装缺少的 Package，并启用已安装但被禁用的 Package。此操作不会更新已安装的版本，也不会禁用组合之外的 Package。

在「应用更改」里勾选「保存为 Recipe」，任务成功后，uBot Manager 会将工程中已启用的 uBot Package 保存为自定义组合，供后续重复使用。

用命令行时，`ubot recipes` 列出组合，`ubot recipe ros-sensors --yes` 应用指定组合，见[命令行 ubot](/manager/cli/)。
