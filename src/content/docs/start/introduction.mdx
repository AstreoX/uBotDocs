uBot 是一组在虚幻引擎（Unreal Engine，UE）5.5 里搭建具身智能（Embodied AI）仿真的插件：给机器人装上传感器，在蓝图里读数据，或者发布到 ROS 2。

## uBot 是什么

uBot 有这几个特点：

- **蓝图优先**：传感器是可以直接在「Components」面板的「Add」菜单里添加的组件，属性、函数和事件都暴露给蓝图，不需要写代码。
- **按需组合**：只装用得上的插件。uBot Manager 会处理依赖，也能一次装好一个[组合](/start/recipes/)（Recipe）。
- **统一的仿真时间**：所有数据用同一个仿真时钟打时间戳，暂停、单步和固定步长都以它为准，见[仿真时钟与采样调度](/concepts/clock-and-scheduling/)。
- **ROS 2 是可选的**：传感器本身不依赖 ROS，要用 ROS 2 时再加 uBotROS。

已发布的插件目前都是 Beta 版本。

文档里有几个约定：

- 节点、引脚和属性的名字保持英文，和蓝图编辑器里显示的一样，用等宽字体，比如 `Update Rate Hz`。
- 示例画成蓝图编辑器里的样子，点任意节点可以看说明和引脚。
- 每个插件手册的页面标题下有一行“需要：…”，写明这一页要哪些插件和版本。
- 每个类、节点和属性的完整说明在参考部分，由 UE 导出的数据自动生成，手册只讲怎么用。
