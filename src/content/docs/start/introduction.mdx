uBot 是一套面向 Unreal Engine（UE）5.5 的具身智能（Embodied AI）仿真插件，具备传感器、统一的仿真时钟、ROS 2 接入等多种功能。借助 UE 的 Lumen、Nanite、物理系统和 Fab 上丰富的资产，可以搭建画面接近真机、场景足够复杂的仿真环境。

搭配 [uBot Manager](/manager/)，可以按需安装，根据需求下载最合适的插件。对新手来说，uBot 也是不错的起点：功能在蓝图中就能使用，不写 C++ 也能上手，文档里面提供直观的蓝图节点展示。

uBot 既有提供仿真时钟、坐标系和统一接口的 [uBotCore](/core/)，也有多样的传感器 [uBotSensor](/sensor/)，还可以通过 [uBotROS](/ros/) 对接 ROS 2，让实机上使用的 ROS 2 算法直接连上仿真。

[uBotAerial](/aerial/) 已经提供多旋翼无人机：导航级和物理级的飞行模型、风、碰撞，以及键盘和手柄手动飞行，面向低空无人机导航和飞控研究。

[uBotPhysics](/physics/) 让同一个 UE 项目、同一个场景里的不同对象，可以由不同的物理后端计算，Chaos 仍是默认；后端是依赖它的独立插件。后续还会提供 [uBotVehicles](/vehicles/) 等插件，面向自动驾驶等场景，以及 [MuJoCo](/mujoco/)、PhysX 等物理后端。

文档里有几个约定：

- 节点、引脚和属性的名字保持英文，和蓝图编辑器里显示的一样，用等宽字体，比如 `Update Rate Hz`。
- 示例画成蓝图编辑器里的样子，点击节点可查看说明与引脚。
- 每个插件手册的页面标题下有一行“需要：…”，写明该页需要哪些插件和版本。
- 每个类、节点和属性的完整说明在参考部分，由 UE 导出的数据自动生成，手册只讲怎么用。
