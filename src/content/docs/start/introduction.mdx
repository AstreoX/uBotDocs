uBot 是一套面向 Unreal Engine（UE）5.5 的具身智能（Embodied AI）仿真插件，具备传感器、统一的仿真时钟、ROS 2 接入等多种功能。开发者可以结合 UE 的 Lumen、Nanite、物理系统与 Fab 资产，构建具有视觉细节和物理交互的仿真场景。

[uBot Manager](/manager/) 支持按需安装插件，并自动处理依赖。uBot 提供蓝图接口，开发者可以通过蓝图使用这些功能；手册中的节点图展示了对应的操作方法。

uBot 既有提供仿真时钟、坐标系和统一接口的 [uBotCore](/core/)，也有多样的传感器 [uBotSensor](/sensor/)，还可以通过 [uBotROS](/ros/) 接入 ROS 2，使机器人算法能够接收仿真数据并发送控制指令。

[uBotAerial](/aerial/) 已经提供多旋翼无人机：导航级和物理级飞行模型、风场与碰撞响应，以及键盘和手柄控制，面向低空无人机导航和飞控研究。

[uBotPhysics](/physics/) 支持在同一 UE 场景中将不同对象分配给不同的物理后端。未绑定其他后端的对象仍由 Chaos 模拟；其他物理后端通过依赖 uBotPhysics 的独立插件提供。后续还会提供 [uBotVehicles](/vehicles/) 等插件，面向自动驾驶等场景，以及 [MuJoCo](/mujoco/)、PhysX 等物理后端。

## 怎么读这份文档

| 使用目标 | 对应文档 |
| --- | --- |

| 安装、更新、移除插件 | [uBot Manager](/manager/) |
| 通过 C++ 调用接口或开发插件 | [开发者](/develop/cpp/) |
| 查询节点或属性 | [参考](/reference/)，按名称检索时使用[节点索引](/reference/nodes/) |
| 查询术语含义 | [术语表](/appendix/glossary/) |

文档采用以下约定：

- 节点、引脚和属性名称与英文蓝图编辑器保持一致，并使用等宽字体，例如 `Update Rate Hz`。
- 示例画成蓝图编辑器里的样子，点击节点可查看说明与引脚。
- 每个插件手册的页面标题下有一行“需要：…”，写明该页需要哪些插件和版本。
- 参考部分由 UE 导出的数据生成，包含类、节点和属性的完整说明；手册说明使用方法和注意事项。
