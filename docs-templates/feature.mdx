## 关键属性

{/* 只列常用的，数值和默认值取自参考；其余链到参考页。 */}

| 属性 | 默认值 | 作用 |
| --- | --- | --- |
| `Update Rate Hz` | 100 | 采样频率，单位 Hz |
| `Auto Start` | true | 开始运行时自动启动 |

## 输出与事件

- `On Imu Data Updated`：每次采样后触发，`Data` 是这一次的 IMU 数据。
- `Get Latest IMUData`：读取最近一次的样本，不会触发新的采样。

## 注意事项

- 角速度和线加速度只在有效样本里有值，先检查帧头的 `Valid`。
